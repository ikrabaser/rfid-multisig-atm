Deneme senaryoları
  1. Küçük çekim: müşteri kartı → PIN → B → tutar → # → A ile parayı al. A'ya basmazsan 8 sn sonra para geri çekilir ve işlem ters kaydedilir.
  2. Onaylı çekim: 10.000 TL üstü çek → ekran "Onay 0/N" der → yetkili kartlarına tıkla → A → PIN. Sağdaki şeritte oylar canlı görünür.
  3. Kasa açma: müdür yrd. ya da müdür kartı (Cem, Deniz, Elif) → A → PIN → diğer yetkililer onaylar → kilit açılır.
  4. İmkânsız seyahat: aynı kartı önce ATM-01'de, sonra terminali ATM-02 yapıp kullan.
